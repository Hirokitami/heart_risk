# Прогнозирование риска сердечно-сосудистых заболеваний

Интеллектуальный модуль на основе методов машинного обучения и Streamlit-приложение для оценки
вероятности наличия сердечно-сосудистого заболевания по данным клинического обследования.

Самостоятельная работа по дисциплине «Алгоритмы и модели машинного обучения»,
Университет «Туран», гр. ИС-262 (2): Серік А.М., Ким Д.В., Янушев Я.Д.

> Учебный прототип. Результат прогноза не является диагнозом и не заменяет консультацию врача.

## Данные

Heart Failure Prediction Dataset (fedesoriano, Kaggle, 2021): 918 пациентов, 11 признаков,
целевая переменная `HeartDisease` (1 — заболевание выявлено, 0 — нет). Файл: `data/heart.csv`.

## Результаты (тестовая выборка, 184 пациента)

| Модель | Accuracy | Precision | Recall | F1 | ROC-AUC | CV ROC-AUC |
|---|---|---|---|---|---|---|
| Логистическая регрессия | 0.886 | 0.893 | 0.902 | 0.898 | 0.939 | 0.916 |
| **Случайный лес (выбрана)** | 0.880 | 0.877 | **0.912** | 0.894 | 0.930 | **0.929** |
| Градиентный бустинг | 0.886 | 0.893 | 0.902 | 0.898 | 0.924 | 0.929 |

Лучшая модель выбирается по ROC-AUC на 5-кратной кросс-валидации (тестовая выборка в выборе не
участвует), при равенстве — по полноте (Recall).

## Установка и запуск

Требуется Python 3.10+.

```bash
pip install -r requirements.txt
python src/train.py          # обучить модели (уже обученные модели лежат в models/)
streamlit run app/app.py     # запустить приложение, откроется в браузере
python tests/test_app.py     # прогнать тестовые сценарии
```

## Входные и выходные данные модели

Вход — 11 признаков: Age, Sex (M/F), ChestPainType (ASY/NAP/ATA/TA), RestingBP, Cholesterol
(0 или пусто — «неизвестно»), FastingBS (0/1), RestingECG (Normal/ST/LVH), MaxHR,
ExerciseAngina (N/Y), Oldpeak, ST_Slope (Up/Flat/Down). Описание диапазонов — `models/feature_schema.json`.

Выход — вероятность наличия заболевания (0…1) и условный уровень риска:
низкий (< 0,33), средний (0,33–0,66), высокий (> 0,66).
